# 📊 ArzStudio - Channel Meta Analysis

Aplikasi ini dibuat untuk menganalisis metadata dari sebuah channel YouTube secara cepat dan akurat.

## 🚀 Fitur Utama
- Analisis metadata channel YouTube.
- Integrasi dengan AI / Gemini API untuk ekstraksi informasi.
- Antarmuka yang intuitif dan responsif.

## 🛠️ Teknologi yang Digunakan
- **Frontend/Backend:** TypeScript, Vite, Node.js
- **AI Integration:** Google AI Studio / Gemini API

## ⚙️ Cara Menjalankan Proyek di Lokal

1. **Clone Repository**
   ```bash
  git clone https://github.com/ArzStudio1/arz.studio-analis.git
cd arz.studio-analis
'''
